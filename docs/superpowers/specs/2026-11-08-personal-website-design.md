# Personal website design (2026-11-08)

Audience: recruiters for SWE / AI / FDE roles.

Design sources: Book of Shapes (work-as-hero uniform card grid, tag filters with counts, generative SVG thumbnails),
uiuxshowcase portfolio examples (separate "Lab" section, concise case studies), Emil Kowalski's apple-design skill
(system font, size-specific tracking, translucent blurred nav, press feedback scale 0.97 / 100ms, reduced motion,
reduced transparency, contrast preferences).

Structure: hero → Featured (Gable, Job Market Tracker, Relay, LeaveBy) → All work with filters
(All / Software & AI / Electrical / Startup) → Lab notebook (EE) → Experience → footer. One page per project:
problem, what I built, result, role, tools, team credit, links.

EE labs: added one at a time from submitted reports after Michelle reviews each draft. Summary and one figure;
no full report PDFs (courses reuse labs). Skip reports that aren't hers.

Hosting: GitHub Pages user site michellemai122.github.io via Actions. Hash routing (#/p/<slug>).

GitHub cleanup (after site): profile README, pins, descriptions, typo renames, archive/delete only with per-repo approval.
